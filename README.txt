PASTELARIA FAMÍLIA & CIA — PROJETO PARA VS CODE

COMO ABRIR
1. Extraia o arquivo ZIP.
2. Abra a pasta "pastelaria_familia_e_cia" no Visual Studio Code.
3. Abra o arquivo index.html com a extensão Live Server (recomendado).
4. Bootstrap é carregado por CDN; mantenha a internet ativa para carregar Bootstrap e fontes.

PÁGINAS INCLUÍDAS
- index.html: página inicial
- cardapio.html: cardápio com filtros e formulário para pedido
- login.html e registro.html: autenticação e cadastro
- perfil.html: edição dos dados do cliente
- reserva.html: solicitação de reserva
- pedidos.html: consulta e atualização de status dos pedidos
- produtos.html: cadastro, edição e exclusão de produtos (administrador)
- usuarios.html: lista de usuários (administrador)

OBSERVAÇÕES IMPORTANTES
- Este projeto é uma demonstração front-end. Os dados são guardados no localStorage do navegador.
- Não existe banco de dados ou servidor/API conectado. Os dados ficam apenas no navegador e não são compartilhados entre dispositivos.
- Para uso real, será necessário desenvolver um back-end, banco de dados e autenticação segura.
- Endereço, telefone, redes sociais e horários reais da pastelaria não foram informados; por isso não foram inventados no site.
